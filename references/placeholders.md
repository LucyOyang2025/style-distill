# 缺素材时的占位策略（占位图 / 示意图）

## 什么时候用

源模板里有图位（hero 图、产品图、人像、场景、纹理底），但**用户没投喂**素材。这时候**不许让图位空着**（图位空着 = 构图就散了，构图是第一优先，见 `style-rules.md` §1），也**不许拿来源不明的网图顶上**。

## 占位顺序（前一步不行才走下一条）

| 顺序 | 做法 | 什么时候走这条 |
| --- | --- | --- |
| 1 · **本机自绘**（首选） | 内联 SVG / Canvas 示意插画 | **图版、UI 示意图、图表位一律走这条**；零版权风险、可复现、与设计令牌 100% 对齐 |
| 2 · **本机生成** | ComfyUI（可复现、免费）/ 即梦（好看但不可复现、每张花钱） | 需要照片级质感、且没有现成素材时 |
| 3 · **免费素材站** | Unsplash · Pexels · Openverse · Wikimedia Commons：检索 → 核许可 → 下载入本地 → 统一处理 | 需要**真实照片质感**时的首选；比动源图干净 |
| 4 · **源模版自身图作临时占位** | 从源站下载 → 走统一链 → 图上/图注显著标注「临时占位 · 待替换」 | 只在前三条**来不及或都不合适**时；用户明确同意过才可这么干 |

## 第 4 条的边界（缺一不可）

源模版自己的图**可以**当临时占位，但只在下面五条全部成立时：

1. **只作临时占位** —— 不得当终稿素材，不得对外宣称是自家作品、自家拍摄或客户案例。
2. **看得出来是占位** —— 图上或图注挂「临时占位 · 待替换」胶囊，不能伪装成终稿。
3. **留痕** —— 源站 URL、下载日期、落位页码/图位，写进 `占位素材清单.md`。
4. **走统一链** —— 按 `unify-assets.md` 做色调/质感/形状收编，否则色调与整套打不齐，比空着更难看。
5. **交付时一次说清** —— 哪几处是源图临时占位、什么时候替换，**逐条列出来**，不夹在正文里；用户点头之后才可外发。

## 免费素材站的准入条件（缺一不可）

- **许可**：CC0 / 公共领域 / 明确免费商用（免署名优先）。**商用受限、需购买、需授权的不用。**
- **留痕**：来源 URL、作者、许可名称、下载日期、许可页截图 —— 写进 `占位素材清单.md`。
- **落地**：**下载到本地再排版**，不许外链热链（外链会失效，也等于替对方分发）。
- **统一**：走 `unify-assets.md` 的处理链，让它与整套风格同调。
- **标注**：图注挂「占位示意图」胶囊 + 来源与许可。
- **兜底**：找不到合规的就**不放图** —— 改留白 + 一行说明，绝不硬凑。

## 三条红线（一直有效）

1. **不伪装**：占位不许标成实拍、不许标成客户案例、不许去水印后当原创。
2. **不抓搜索结果**：右键另存的"网络图片"、来源不明的图，一律不算素材。
3. **不夹带**：待替换项必须在交付时点名，不许藏在正文里蒙混过关。

## 怎么检索

- 关键词 = 源的构图词（满幅远景 / 俯拍平铺 / 单物特写 / 群像）+ 调性词（DNA 的 `tone.words`）+ 画幅比（源的 `media.aspect_ratios` 主值；hero 用 `imagery.hero.natural` 算出的比例）。
- 优先站点：**Unsplash · Pexels · Wikimedia Commons · Openverse**（都能按许可筛）。用 `firecrawl` 技能检索与抓取，别手抄 URL。
- 每次抓 **3 张候选**（1 入选 + 1 备选 + 1 对比），说清为什么选它：色调、光照方向、留白、可裁切余量、与源 hero 的构图相似度。
- 源是**去饱和冷调 + 一条暖色光带**这类特征时，选图先看**光照与留白**，再靠 `unify-assets.md` 把色调拉齐 —— 别指望一次就找到色调完全一致的图。

## 交付纪律

`占位素材清单.md` 与文档一起交，逐项写：文件 · 来源 URL · 作者 · 许可 · 落位（哪一页哪个图位）· 状态（**占位 / 源图临时占位 / 待替换**）· 替换时机。对外发出前，把"待替换项"一次说清。
