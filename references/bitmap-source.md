# 位图源路线（活体页面进不去时怎么办）

真站被 Cloudflare / 登录墙拦死、拿不到 computed style 时，**不要放弃、也不要凭感觉编**：
改用条目页代管的整页截图，把**量得出来的照量**（色彩面积比、版心、比例、字阶的近似值），
**量不出来的如实标 unverified**（computed 字号阶梯、栏数、间距频次、圆角半径）。

2026-09-19 实测跑通：land-book #99993「Weave」——真站 `curl` 403，借浏览器上下文打开条目页
也频繁触发人机校验，于是整轮走本路线，门禁拿到「主色承接 0.97 / 色相 0.013 / 明度 0.056」。

## 一、取图

条目页本身 403 时，先把**页内那张代管截图**的 URL 取出来（借浏览器上下文跑一次
`page.$$eval('img', …)`），再 `curl` 直下（CDN 图片 URL 带签名，通常不需要 cookie）。
拿到的常是 2000px 宽的整页长图（可 10000px 高）。**先验尺寸**：
`ffprobe -v error -show_entries stream=width,height -of csv=p=0 图.webp`。

## 二、三件套（`scripts/` 里，零依赖，喂 PNG）

```bash
node $S/dna-probe.mjs ./整页截图.png --out dna.json     # 位图模式：8 色 k-means（含面积份额）+ 明度/色相直方图
node $S/probe-margins.mjs ./整页截图.png                # 内容左右边界（版心）+ 整行均值找深色带
node $S/probe-lines.mjs  ./整页截图.png <y0> <y1>       # 逐行墨量切「文字行」→ 行高分布（当字阶用）
node $S/probe-palette.mjs ./整页截图.png                # 高频色桶 + 最饱和色簇（把 accent 值取准）
```

- `probe-palette` 是必要的：k-means 会把 accent 和它的抗锯齿边缘平均成一团，**主色要按「最饱和色簇」取**。
- `probe-lines` 的行高 ≠ 字号，但**层级比例是对的**（例：大标题行高 70 / 小标题 35 / 正文 18–19 / 微标签 12），
  按这个比例给字阶，落地后再用页图复核。
- `probe-margins` 同时给出**深色带位置**（例：只剩末尾 88.9%–100% ⇒ 排版上「全浅 + 深色收尾页」）。

## 三、跑门禁前先算「源自己的基准值」

位图模式下「字号阶梯」「栏数一致」**天然读不到** —— 如实写「读不到」，**不许当成过了**。

更要紧的是：**先量源自己在那道门禁上的值**。Weave 这轮「图像策略（照片感）」不过（产出 0.033 < 门槛 0.12），
但**源自己只有 0.043** —— 门槛假设「源是照片型」，而它不是。这种情况**不要硬追数字**（别为了让指标好看塞照片），
照实写：「门槛假设在源身上不成立 + 双方实测值 + 属量法差异」。

## 四、四个坑（都踩过）

1. **页底要铺源的主底色**。源是「浅灰底 + 白卡」时，若把页做成白底、卡片又白 ⇒ 卡片在白底上**消失**
   （像素体检会报「内容止」只到 0.73）。写 `@page{background:#F3F2F0}` 铺满整张纸 + 白卡，立刻正常。
2. **嵌套数组 `join('')` 会掺进逗号，逗号在 grid 里变成匿名网格项**，把 `span 4` 的三张卡挤掉一行
   （症状：三张卡排成两行 + 版心溢出）。用 `cells.flat(3).join('')`。
3. **`justify-content:space-between` 只有两三个块时会留出 ≥25% 的大空带**（像素体检直接报「空带」）。
   主块加 `flex:1` 自己撑满，块内再 distribute。
4. **白色卡片在白底页上量不出边界**：像素体检的「墨量」只认暗像素，别拿它判断卡片是否可见 —— 看渲染图。

## 五、换风格源不必重做素材

把界面图配色收编进新模版时，**只换调色映射表的右值**（`scripts/make-recolor-map.mjs` 的 `MAP`），
源色值不动；重抓一次即可。实测同一张图换表前后**逐色面积占比完全一致**
（`#F5F5F5`→`#FDFDFD` 都是 23.2%、主色 `#FF531F`→`#9C4C3B` 都是 0.8%）——
**词典、文案、抓图规格全部复用，不重收串也不重译**。
